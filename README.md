# SQLD 공개 학습 노트

개념을 이해하고 작은 데이터의 결과를 계산하는 한국어 학습 웹입니다. 1과목 10단원·2과목 18단원, 직접 작성한 복습문제 34개와 개념도 3개를 제공합니다. 공식 시험 안내나 전 범위 교재를 대체하지 않습니다.

## 자료 수정

`public-materials/`의 Markdown을 수정한 뒤 실행합니다.

```sh
python -m pip install -r requirements.txt
python site/build.py
node --check site/dist/app.js
python -m http.server 4173 --bind 127.0.0.1 --directory site/dist
```

`http://127.0.0.1:4173`에서 확인합니다. 원문과 생성된 `site/dist/`를 함께 커밋합니다. 디자인·기능은 `site/dist/index.html`, `style.css`, `diagram.css`, `app.js`에서 수정합니다. 관리자 업로드 화면은 없습니다.

## 출처와 공개 범위

각 과목의 마지막 참고자료 및 각 절 링크에 공식 문서와 참고 강의를 표시했습니다. 설명·가상 데이터·문제는 공개용으로 새로 작성했으며 원본 PDF·영상·자막·유료 노트를 포함하지 않습니다. 참고자료의 권리는 원권리자에게 있으며 출처 표시가 그 자료의 재배포 허락을 뜻하지 않습니다. 제작자의 감수·제휴 자료가 아닙니다.

이 저장소는 공개본만으로 시작하며 개인 학습용 요약본의 과거 커밋을 포함하지 않습니다. 이슈에는 개인정보나 원문 자료 전체를 올리지 말고 단원·수정 이유·확인 가능한 링크를 남겨주세요.

## 검증과 저장

공통 대여 예제의 집계·NULL·조인·서브쿼리·윈도우 함수 등 15개 결과를 SQLite에서 확인했습니다. Oracle 전용 문법은 공식 문서와 대조했으며 Oracle/SQL Server 엔진 실행 검증은 하지 않았습니다.

진도·북마크·답안은 방문자 브라우저에 저장되며 서버로 전송하지 않습니다. 기기 간 동기화는 없습니다.

## Vercel

무료 Hobby 플랜의 개인·비상업 프로젝트 용도로 배포를 준비합니다. Framework는 Other, 출력 폴더는 `site/dist`, 빌드 명령은 없습니다. 생성 결과가 저장소에 포함됩니다. 실제 배포 주소는 배포 완료 후 기록합니다.
